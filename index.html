Method, not magic

            
A practical prompt rubric

            

              Prompt Prism turns prompt design into an inspectable craft with
              five clear lenses.
            

          

        

        

          

            01
            
Intent

            

              Name the task and use a direct action verb. The evaluator looks
              for explicit purpose, not prose length.
            

          

          

            02
            
Context

            

              Give the audience, source material, situation, and relevant
              background the instruction depends on.
            

          

          

            03
            
Constraints

            

              Define boundaries: length, must-have criteria, exclusions, and how
              uncertainty should be handled.
            

          

          

            04
            
Output

            

              Specify the response shape with a format, sections, fields, or a
              short example.
            

          

          

            05
            
Guardrails

            

              Tell the system what to do when information is missing and
              discourage invented facts.

How scoring works

            
Transparent by construction

            

              The analyzer uses visible keyword, structure, and length checks in
              app.js. It is intentionally deterministic: the same
              prompt always earns the same result.
